# Imob Velocity 5.0 — Changelog

- Adicionada versão PWA instalável.
- Manifesto web com identidade Imob Velocity e ícones próprios.
- Service worker com cache do app shell e assets visuais.
- Modo local disponível offline após primeiro carregamento da PWA.
- Botão de instalação PWA quando suportado pelo navegador.
- Suporte de orientação para instalação em Android/desktop; instrução específica para iOS quando aplicável.
- Corrigidos MIME types de `.webp` e `.webmanifest` no servidor.
- Service worker servido sem cache prolongado para facilitar atualizações.
- Versão Standalone mantida como HTML autocontido para abertura direta.
- Cenas preservadas em ritmo mais confortável: 0,5× / 1× / 2×, padrão 1×.
- Anúncio de compra preservado com nome dinâmico do participante que efetivamente comprou o veículo.
- Núcleo e servidor atualizados para versão 5.0.0.
